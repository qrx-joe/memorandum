## 🚧 计划中

### P0：体验改进

- [ ] **深色模式**：基于 `prefers-color-scheme` 自动切换 + 手动 toggle
- [ ] **Markdown 编辑器**：集成 SimpleMDE 或 ByteMD，预览/编辑双模式
  - 候选：SimpleMDE（轻量）、ByteMD（实时预览）
- [ ] **快速记录入口**：首页浮动输入框，无需跳转

### P1：数据能力

- [ ] **回收站**：软删除（`is_deleted=true`）+ 30 天自动清理
- [ ] **数据导出**：JSON（完整备份）/ Markdown（单篇/批量）/ PDF（打印）
- [ ] **SQLite 迁移**：从 JSON 迁移到 SQLite，提升并发与查询性能
  - 迁移脚本须保证现有 JSON 数据无损导入

### P2：架构升级

- [ ] **REST API 拆分**：分离 `/api/*` 与 `/static/*`，支持前后端分离
- [ ] **可选前端框架**：Alpine.js（轻量交互）或 Vue 3 CDN（响应式）
- [ ] **部署方案**：Dockerfile + Railway/Fly.io 部署文档
