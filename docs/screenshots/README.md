# 截图占位说明

将下列截图放到本目录后，主 README 即可正常引用。

| 文件名 | 内容 | 推荐尺寸 |
|--------|------|----------|
| `home.png` | 首页空状态（左侧栏 + 随机引言） | 1440 × 900 |
| `detail.png` | 选中一条笔记的详情页（标签 + 时间 + 操作按钮） | 1440 × 900 |
| `edit.png` | 编辑模式表单 | 1440 × 900 |
| `tag-filter.png` | 标签筛选效果（左侧标签高亮 + 列表过滤） | 1440 × 900 |
| `mobile.png` | 移动端响应式布局 | 375 × 812 |

## 截图建议

1. 启动应用后填几条具有代表性的笔记（带标签、置顶 1 条）
2. 截图前清空浏览器开发者工具，关闭书签栏
3. 浏览器缩放保持 100%
4. PNG 格式，单张 ≤ 500 KB（必要时用 [tinypng.com](https://tinypng.com) 压缩）
